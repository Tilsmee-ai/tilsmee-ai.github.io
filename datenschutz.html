Hosting

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf können technisch notwendige Verbindungsdaten durch den Hostinganbieter verarbeitet werden.

Wetter und Standort

Die Standortabfrage erfolgt nur nach deiner Zustimmung. Ohne Freigabe verwendet die Website Geldern als Ersatzstandort. Wetterdaten werden über Open-Meteo abgerufen.

Akkustand

Wenn der Browser die Battery Status API unterstützt, wird der Akkustand nur lokal im Browser ausgelesen und nicht gespeichert.
